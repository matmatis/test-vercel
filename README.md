# My First Vercel Project

This is a simple static website created to help you learn how to deploy on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy to Vercel

### Option 1: GitHub import

1. Push this folder to GitHub.
2. Go to https://vercel.com and sign in.
3. Click "Add New Project".
4. Import your GitHub repository.
5. Keep the default settings and click "Deploy".

### Option 2: Vercel CLI

```bash
npx vercel
```

Follow the prompts to log in and deploy the project.

## Files

- `index.html` contains the page content.
- `styles.css` contains the styling.
- `package.json` defines the local dev script.
